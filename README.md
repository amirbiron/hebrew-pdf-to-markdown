# PDF עברי ל-Markdown

ממיר PDF בעברית ובעברית-אנגלית מעורבת ל-Markdown, שמסמן בבירור כל עמוד שהוא לא בטוח בו. הגרסה הראשונה מתוכננת כדף באתר: מעלים קובץ, מקבלים Markdown, ולצד כל עמוד שסומן מופיעה אזהרה עם הסיבה.

## למה

כל ספריות החילוץ שנבדקו (pdf_oxide, poppler, PyMuPDF, pypdfium2, Unstructured) שוברות עברית בחלק מהקבצים: מילים הפוכות, אנגלית הפוכה בתוך עברית, פיסוק שקופץ לתחילת השורה, מספרים שזזים בין עמודות בטבלה. והן עושות את זה בשקט, בלי שום סימן שמשהו לא בסדר.

הממצא המרכזי מהבדיקות: **הקבצים עצמם תקינים.** בכל 12 קובצי הבדיקה, משמונה תוכנות יצירה שונות, העברית שמורה בסדר הנכון. מה ששובר אותה הם הקוראים, שמנסים "לתקן" סדר ומקלקלים. לכן הגישה היא קורא אחד (pypdfium2) שבונה כל שורה לפי מיקום האותיות על הדף, ובדיקות שמסמנות עמודים לא ודאיים.

## מבנה

| תיקייה | מה יש בה |
|---|---|
| `prototype/` | אב-טיפוס של בונה השורות (כ-40 שורות לוגיקה), עם הבדיקות העקיפות ורשימת הכשלים הידועים בראש הקובץ |
| `testset/pdfs/` | 12 קובצי PDF אמיתיים, סט הבדיקה הקבוע |
| `testset/README.md` | פירוט הקבצים: איזו תוכנה יצרה כל אחד ומה מיוחד בו |

## הרצה

```bash
pip install -r requirements.txt
python prototype/hebrew_pdf_prototype.py testset/pdfs/mentoros-overview_weasyprint.pdf
python prototype/hebrew_pdf_prototype.py --score testset/pdfs
```

## מצב

אב-טיפוס בלבד. השלב הבא לפי מסמך האפיון: סט בדיקה עם 40 שורות מתויגות ביד, ואחריו בונה השורות כקוד מסודר, התיקונים אחד-אחד, ציון וסימון, טבלאות פשוטות, ובסוף הדף באתר.
